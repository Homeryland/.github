## Introduction

Build what you need with your own automation infrastructure or our strong cloud-native automation infrastructure -- using low code, simple commands, or natural conversation.

We believe every complex and useful things can be broken down into small automation pieces.

Our projects focus on:

- C++, Rust -- reliable, performant, and maintainable systems
- Cloud-native infrastructure -- modern deployments and runtime technologies
- Self-hosting -- run your software on your own infrastructure
- Developer tools -- tools that make building and deploying easier
- Extensibility -- modular systems that can evolve through plugins and integrations
- Security -- secure authentication, authorization and infrastructure

## Products

### DryDrop

Your self-hosted automation platform.

DryDrop is an open-source project exploring a developer-friendly way to build, deploy, and manage applications across your own infrastructure.

Avaliable for CLI, TUI, Mobile, Desktop and Web.

For more information about DryDrop at [DryDrop](https://drydrop.homeryland.org)
