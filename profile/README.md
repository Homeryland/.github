Homeryland

Build software. Own your infrastructure.

Homeryland is an independent software company focused on building developer tools, infrastructure, and self-hosted software.

We believe software should be simple to build, easy to deploy, and under your control.

  

What We Build

Homeryland explores the space between local development, cloud infrastructure, and self-hosting.

Our projects focus on:

- 🦀 Rust — reliable, performant, and maintainable systems
- ☁️ Cloud-native infrastructure — modern deployment and runtime technologies
- 🏠 Self-hosting — run your software on your own infrastructure
- 🛠️ Developer tools — tools that make building and deploying software easier
- 🔌 Extensibility — modular systems that can evolve through plugins and integrations
- 🔐 Security — secure authentication, authorization, and infrastructure

DryDrop

Philosophy

Own Your Software

Your source code, infrastructure, and deployments should not have to depend on a single platform.

Local First

Development should work naturally on your own machine before moving to remote infrastructure.

Open Source

We build in the open whenever possible, so ideas, implementations, and tools can be shared with the community.

Composable

Software infrastructure should be modular. Plugins and integrations should make it possible to extend a system without making its core unnecessarily large.

Built with Rust

Rust is our primary systems programming language because we value performance, reliability, safety, and long-term maintainability.

Make powerful infrastructure accessible without giving up ownership.
